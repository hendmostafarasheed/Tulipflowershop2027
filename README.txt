TULIP FLOWER SHOP INVITATION
============================

Flat ZIP contents (no folders):
- index.html  : first page / animated cover
- page2.html  : second page / interactive buttons
- style.css
- script.js
- cover.gif
- page2.gif

GitHub Pages:
1. Extract this ZIP.
2. Upload all six files directly into the repository root (not inside a folder).
3. Commit/publish. Open index.html through your GitHub Pages URL.

Button actions:
- OPEN INVITATION -> page2.html
- OUR LOCATION -> Google Maps search for Tulip Flower Shop
- CALL US -> Google search to find the shop's phone number
- SHARE -> native share sheet or copies the invitation URL
- SPECIAL OFFERS -> opens an on-page offers panel with a search link

Important:
The shop's exact address and phone number were not provided, so the location and call
buttons use live search links rather than a verified specific map pin or direct phone call.
Replace those URLs in page2.html with the shop's exact Google Maps link and tel:+countrycode...
number when available.

Music:
- music.mp3 is included and set to autoplay/loop on both pages.
- Some mobile browsers block autoplay with sound until the visitor taps the page.
